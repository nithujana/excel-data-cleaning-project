# Excel Data Cleaning Project

## Project Overview
This project demonstrates how raw business data can be transformed into a clean, analysis-ready dataset using Microsoft Excel.

## Dataset
The dataset contains:
- Client Information
- Contact Details
- Department and Location
- Payment Methods
- Revenue and Profit Data

## Data Cleaning Tasks
- Auto-fitted rows and columns
- Standardized text formatting
- Applied LOWER, TRIM, and PROPER functions
- Split Department and City using Text to Columns
- Removed duplicate records
- Filled missing values with N/A
- Handled formula errors using IFERROR
- Improved formatting and readability

## Tools Used
- Microsoft Excel
- Text to Columns
- Remove Duplicates
- Find & Replace
- TRIM()
- PROPER()
- LOWER()
- IFERROR()
